# 闇の伝説 公開DB用 画像パッケージ

公開用スペックDB（Muse スペース）から参照するための画像一式です。
画像はすべて PNG（透過あり・無変換）で、DB のキー名で配置しています。

## 中身

|---|---|---:|
| `images/jp/monsters/` | モンスタースプライト（`mns001.png`〜、番号＝JP mns番号） | 534 |
| `images/jp/items/` | アイテムアイコン（DBキー名） | 182 |
| `images/jp/skills/` | スキルアイコン（DBキー名） | 61 |
| `images/jp/spells/` | 魔法アイコン（DBキー名） | 98 |

| `mapping.json` | キー → リポジトリ内相対パスの対応表 | — |

合計 1,540 枚。

画像が無いキー（実データ側で同定できなかったため、推測で埋めていません）：
アイテム10件 ― `con-002`（コマディウム）、`wpn-fst-010`〜`wpn-fst-018`（三節棍9種）。

## GitHub へのアップロード手順

1. GitHub で新しいリポジトリを作成します（Public）。
2. このフォルダの中身（`images/`、`mapping.json`、`README.md`）をそのままリポジトリ直下にアップロードします。
   - 画面から上げる場合：リポジトリ画面の「Add file」→「Upload files」でフォルダごとドラッグ＆ドロップ。
   - git が使える場合：このフォルダで `git init` → `git add .` → `git commit` → リポジトリへ `git push`。
3. アップロード後、各画像の公開URLは次の形になります：

   `https://raw.githubusercontent.com/<ユーザー名>/<リポジトリ名>/main/images/jp/items/arm-001.png`

   公開DB側では `mapping.json` の相対パスにこのベースURLを前置して参照します。
   画像を差し替えたいときは、同じファイル名で上書きアップロードすれば、URLは変わらず中身だけ差し替わります。
